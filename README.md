## 🌌 The Core Experience

**MUGHEES_OS** is not just a landing page; it is a simulated, high-performance terminal emulator that feels like a live neural connection running Mughees's mind. The interface balances high-fidelity WebGL graphics with a low-level retro CLI look.

### 1. Interactive 3D Particle Universe (`particles-three.js` & `particle-targets.js`)
Powered by **WebGL and Three.js**, the background renders a fluid particle cloud that dynamically shifts shape.
* **Morphing States**: The particle system adapts and snaps into various geometric formations depending on the current active section of the portfolio.
* **Haptic Drag/Pull**: Clicking and dragging on the canvas exerts a simulated gravity field, pulling floating stars and constellations toward the cursor.

### 2. Neural Node Grid Canvas (`neural-bg.js`)
An additional canvas layer overlaying the skills graph renders an interactive 2D node-net representing a synapse network.
* **Synapse Activity**: Connected nodes light up and pulse relative to simulated network load and user focus coordinates.
* **Reduced Motion Compliant**: Automatically detects client settings and downgrades to standard vector assets to save cycles and respect accessibility criteria.

### 3. MUGHEES.AI Copilot Chatbot (`mughees-ai.js`)
An embedded local AI chat assistant representing a digital clone of Mughees.
* **Local Knowledge Base**: Reads from `data/mughees-profile.js` to process and reply to user queries about projects, skills, education, and credentials entirely client-side.
* **Query Routing**: Features intent-matching rules with direct suggestion chips to guide prospective recruiters and visitors through Mughees's highlights.

### 4. Interactive Retro Game Mode (`game-mode.js`)
Click the gamepad joystick toggle on the top-right header to activate **Game Mode**—an inline canvas-rendered grid adventure!
* **Controls**: Navigate using **WASD** or **Arrow Keys**.
* **Objective**: Move the player character through the interactive overlay to collect **5 hidden Data Shards** to reveal confidential records.
* **Interaction**: Press **Space** to inspect and decode environmental elements.

### 5. Live GitHub Uplink Ticker (`github-feed.js`)
A live horizontal news-ticker fetching and displaying live contribution logs directly from the GitHub API feed.
* Shows active commit structures, pushes, and repository events in a terminal status board.

### 6. Physical Micro-Animations & Magnetic Haptics (`magnetic-hover.js` & `glitch.js`)
* **Magnetic pull**: Nav links, console action buttons, and portraits physically slide toward the cursor on hover with elastic spring physics.
* **Hardware Glitches**: Section transitions trigger a random screen glitch flash, CRT scanline overlay, and custom command typing prompts.

## 🚀 Local Installation & Setup

Running this portfolio locally is simple because it is built entirely using vanilla modular components and imports.

### Prerequisites
You will need a local HTTP server to resolve modular ES6 javascript imports safely.

### Option A: VS Code Live Server (Easiest)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Click the **Go Live** button in the status bar at the bottom right.
4. The site will launch on `http://127.0.0.1:5500/`.

### Option B: Node.js (Static Server)
If you have Node.js installed, launch a local web server instantly using `npx`:
```bash
# From the project root folder:
npx serve .
```
Open `http://localhost:3000` in your web browser.

### Option C: Python Server
If you prefer Python, you can run:
```bash
# Python 3+
python -m http.server 8000
```
Open `http://localhost:8000` in your browser.
